# Footy Life Manager — build de teste

Jogo de simulação de futebol (vida de jogador + manager), mobile-first. **Da peneira à lenda.**

Esta pasta contém o **build de teste** pronto pra hospedar: um único arquivo `index.html`, autossuficiente.

## Jogar / testar

Abra o link do GitHub Pages no celular (Chrome) ou no PC. **Precisa de internet** (carrega React/Babel de um CDN). O progresso fica salvo no navegador.

## Versão

`v9.83-vs1` — Modo Carreira em fase de QA.

> Build standalone gerado a partir do projeto principal (`brasil-manager.jsx` → `pack.mjs`). Para atualizar o teste, basta substituir o `index.html` por uma nova versão do `footy-life-manager.html`.
